# 学习通课件下载器（Chrome 扩展）

一键下载学习通（Chaoxing）课程页面里的 **PPT/PPTX/PDF/Word 等课件原件**，适用于 `mooc1.chaoxing.com`、`mooc1-2.chaoxing.com`、`mooc2-ans.chaoxing.com` 等各类学习通课程学习页。

## 工作原理（已在真实页面实测）

1. 内容脚本在学习通页面抓取课件卡片 `iframe[objectid]`，从 `data` 属性拿到 `objectid / 文件名 / 类型 / 页数`。
2. 课件预览器地址形如 `https://pan-yz.chaoxing.com/screen/v2/file_<objectid>?...&signature=...`，页面里自带 `fileinfo` 对象，其中有原件直链：
   `https://d0.cldisk.com/download/<objectid>?at_=..&ak_=..&ad_=..&fn=..`
3. **关键**：这条直链校验 Referer，必须由预览页发起请求（直接开链接/后台请求都会 403，已实测）。所以扩展让**预览器帧里的内容脚本用 `<a>` 点击触发下载**，浏览器自动带上正确的 Referer，文件以服务器给的原始文件名（如 `坐骨神经腓肠肌标本制备.pptx`）保存。
4. 课件没打开过时，扩展会用已捕获的签名预览地址开一个后台标签页（URL 末尾加 `#cxdl`），进入后自动点下载并自行关闭。
5. 老师禁止下载原件时，可退而用「页面图片」把每页幻灯片图片（`s3.cldisk.com` 的公开缩略图）逐张保存。

## 安装

1. 新建文件夹（如 `chaoxing-ppt-downloader`），放入 5 个文件：
   `manifest.json`、`background.js`、`content.js`、`popup.html`、`popup.js`
2. Chrome 地址栏打开 `chrome://extensions/`
3. 打开右上角 **开发者模式**
4. 点 **加载已解压的扩展程序**，选择该文件夹
5. 建议在扩展详情里允许访问 `chaoxing.com` 相关站点，并把图标固定到工具栏

## 使用

1. 登录学习通，打开包含 PPT/文档的课程章节页。
2. 等 1~2 秒让课件预览加载，点工具栏扩展图标。
3. 弹窗列出检测到的课件（文件名、类型、大小、页数）。
4. 点 **⬇️ 下载原件** → PPTX/PDF 原文件进下载目录（文件名保持原名）。
5. 点 **🖼️ 页面图片** → 每页幻灯片图片逐张保存（原件被禁时的兜底）。

## 常见问题

- **更新代码后要重新加载**：`chrome://extensions/` → 找到本扩展 → 点刷新（🔄）图标；已打开的学习通页面需刷新一次才会跑新脚本。
- **弹窗显示“还没发现课件”**：当前页面没有文档卡片或课件未加载。切到课程学习页，滚动到课件位置让它渲染，再点「刷新检测」。
- **提示“拿不到预览地址”**：先在页面上点开该课件预览（让它加载出来），再点「下载原件」。
- **只想要图片**：图片走公开 CDN，任意时机都可下载；图片是缩略图分辨率，原件优先。
- **直链有时效**：`at_/ak_/ad_` 签名是短期的，每次点「下载原件」扩展都会重新取新链接，无需手动刷新。

## 说明

- 扩展只读取页面上已有的信息（objectid、文件名、预览器返回的直链），用你自己的学习通登录态下载你有权限查看的课件，请勿传播。
